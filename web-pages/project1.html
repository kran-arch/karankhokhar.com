/Project — Portfolio Website

Built entirely by hand using HTML, CSS, and JavaScript—without templates or page builders—this portfolio was crafted to master core front-end fundamentals. Focusing on clean semantic structure, responsive layouts, and a distinct visual identity, it served as a hands-on project to gain fluency in web development while doubling as an interactive resume.

HTML5 CSS3 JavaScript

Overview & Features

A multi-page site with sections for About, Education, Experience, Skills, and Projects. Built with a blueprint-inspired design, custom title blocks, and lightweight CSS micro-interactions.

Design Inspiration

The design and core inspiration for this portfolio draw heavily from engineer and creative technologist Gazi Jarin. Known for her developer content, Gazi is a Software Engineer at Google who builds projects across machine learning, hardware, and game development.

Her portfolio stands out in the developer community for its sleek, dark-mode visual identity, clean typography, minimalist layout, and thoughtful presentation of personal projects and technical milestones. Modeling my portfolio after her work provided both a high standard for aesthetic design and a blueprint for showcasing technical expertise alongside personal identity.
